**Tourism Translation for Indian Languages** &nbsp;·&nbsp; 🚧 *in progress*

Evaluating how well today's models translate tourism and cultural text into Indian languages, then improving on them.

- 📚 Dataset: FLORES-200 plus my own tourism passages, across 2–3 Indian languages
- 📏 Baselines: API models and a small open model, scored with **chrF** and **COMET**
- 🛠️ Next: **LoRA fine-tuning**, human evaluation, and error analysis (place names, cultural terms, scripts)
- 📝 Write-up and code will be published here in early 2027
